# 22. AI 下書き生成（Google Gemini API）

**依存**: 16（15 の画像縮小を共用）
**参照**: REQUIREMENTS_phase2.md §9
**マイルストーン**: M2

## 目的

走り書きメモ+写真から、記録カードの「テーマ」「ひとことメモ」の下書きを Gemini API に作らせ、週6回運用の負荷を下げる。**AI はあくまで補助**であり、必ず人が確認・手直しして公開する。API 障害時も手動入力だけで完結できること。

## Todo

- [ ] env: `GEMINI_API_KEY`（サーバー専用・クライアントに露出させない）と `GEMINI_MODEL`（**モデル ID を差し替え可能に**。既定は現行世代の Flash 系。Gemini は旧世代の提供終了が早いためハードコード禁止）。`.env.local` と Vercel（Production）に設定（運用者タスク）
- [ ] 実装着手前に最新の公式情報を確認する: SDK（`@google/genai` 系）の現行 API・無料枠の最新条件・推奨 Flash モデル ID（Context7 / Google AI Studio 公式ドキュメント）
- [ ] Server Action `generateDraft`: 走り書きメモ+アップロード済み写真（`image.ts` で**縮小してから**送信・通信量節約）→ Gemini から「テーマ（短い見出し）」「ひとことメモ（です・ます調2〜3文）」を構造化して受け取る
- [ ] 生成プロンプトを設計しコードに定数として管理する: シニア向け教室の温かいトーン / です・ます調2〜3文 / テーマは短い体言止め / 個人名・個人情報を出力しない
- [ ] `RecordForm` に「AIに下書きを作ってもらう」ボタンを追加: 実行中はローディング表示 → 成功でテーマ・メモ欄に反映（**編集可能なまま**・非制御入力への反映方法に注意）→ そのまま手直しして保存できる
- [ ] エラーハンドリング: タイムアウト・レート制限（429）・API 障害は分かりやすい文言のトーストにする（握りつぶさない）。失敗しても手動入力での作成・公開は一切妨げない
- [ ] AI 出力の自動公開はしない（フォームに反映するだけ。公開は人の操作のみ・要件 §15）
- [ ] 運用ルールを README または CLAUDE.md に明記する: **個人情報を含むスクショ・メモを AI に送らない**（無料枠の入力は Google の製品改善に利用されうるため）

## 完了条件

- メモ+写真から下書きが生成されフォームに反映され、手直し→公開の一連が数分で完了する
- `GEMINI_MODEL` の値を変えるだけでモデルを切り替えられる
- API キー未設定・API 障害の状態でも、記録カードの手動作成・公開が問題なく行える
