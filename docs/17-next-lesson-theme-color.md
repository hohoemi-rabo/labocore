### 実装中に確定した事項

- [x] **`revalidatePath("/records")` のバグを修正**（16 で作り込んだもの）。既定の type は `"page"` で**そのパスだけ**が対象。配下の `/records/next-lessons`・`/records/announcements` が古いまま残るため `"layout"` 指定にした
- [x] **`revalidateClasses()` を追加**。コマの作成・更新・**廃止**でも生徒向けを再検証する。廃止したコマは生徒向けのクラスタブ・クラスえらびから消える必要があるが、16 までは再検証していなかった
- [x] **入力は制御コンポーネント**にした。非制御だと「未定に戻す」で DB を空にしたとき、**一度でも触った入力欄には古い値が残り、触っていない欄だけ消える**というちぐはぐな見え方になる（HTML の dirty value flag の挙動）。サーバー値の署名が変わったときだけ追従させ（React の「レンダー中に state を調整する」パターン）、**他カードの保存では自分の入力が消えない**
  - カードの `key` は**コマの id 固定**。可変の値を混ぜると再マウントして入力中の内容が飛ぶ
  - 一覧の並びは `weekday`→`start_time` 固定。保存で変わる値で並べると1件保存しただけで並び替わる
- [x] **`<form>` 要素を使わない**（16 と同じ理由 + `ConfirmDialog` の入れ子回避）。`useActionState` に**型付きペイロード**を渡す形にし、`FormData` を経由しない
- [x] 「未定に戻す」は**別アクション**（`clearNextLesson`）。検証の必要がない操作を、検証で弾かれうる経路に通さない
- [x] 日付は `z.iso.date()` で暦の妥当性まで見る（正規表現だと `2026-13-45` が通り、Postgres の `22008` が「保存に失敗しました」に化ける）
- [x] `theme_color` は小文字へ正規化してから **`z.enum` でパレットの6色に限定**。`defaultChecked` の判定も小文字化して突き合わせる（DB に大文字が入っているとどれにも一致せず未選択のまま送信されてしまう）
- [x] トーストは**ページに1つ**（カードごとに持つと `position: fixed` の通知が重なる）
