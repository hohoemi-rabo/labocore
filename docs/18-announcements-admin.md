# 18. 管理: お知らせ管理

**依存**: 14, 16（ナビ・`/records` 配下を使う）
**参照**: REQUIREMENTS_phase2.md §8.3
**マイルストーン**: M1

## 目的

教室からのお知らせ（全体向け/クラス別・掲載期間つき）を CRUD できるようにする。掲載期間を過ぎたものは自動で生徒向けに出なくなる（RLS で担保・消し忘れ防止）。

## Todo

- [ ] `/records/announcements` 一覧（v2 デザイン）: 掲載中 → 掲載予定 → 期限切れ の順で分かりやすく表示。**期限切れは muted 表示**（要件 §8.3）
- [ ] `new` / `[id]/edit` + 共有フォーム: タイトル / 本文 / 対象（全体 or 特定クラス・セレクト）/ 掲載開始日 / 掲載終了日
- [ ] Zod 検証: `ends_on >= starts_on`。違反はフィールドエラーで表示
- [ ] 削除: **物理削除** + `ConfirmDialog`
- [ ] 変更成功時は `/records/announcements` と `/kiroku` 系を `revalidatePath` する
- [ ] 期間の自動非表示が RLS（14 の JST 判定ポリシー）で効いていることを動作確認する（期限切れを1件作り anon で読めないこと）

## 完了条件

- お知らせを CRUD でき、対象（全体/クラス別）と掲載期間どおりに生徒向け表示が制御される
