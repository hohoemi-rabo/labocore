# 18. 管理: お知らせ管理

**依存**: 14, 16（ナビ・`/records` 配下を使う）
**参照**: REQUIREMENTS_phase2.md §8.3
**マイルストーン**: M1

## 目的

教室からのお知らせ（全体向け/クラス別・掲載期間つき）を CRUD できるようにする。掲載期間を過ぎたものは自動で生徒向けに出なくなる（RLS で担保・消し忘れ防止）。

### 実装中に確定した事項

## 後続チケットへの申し送り

- **20（重要）**: `/kiroku` 配下に **`export const dynamic = "force-dynamic"` が必要**。生徒向けは anon で読むため cookie クライアントを使わず、管理画面と違ってルートキャッシュが効く。掲載期間は時刻で状態が変わるのに、**日付をまたいでも何のミューテーションも起きないので `revalidatePath` が走らない**。そのままだと期限切れのお知らせが生徒に表示され続ける。チケット20 の Todo に確認手順ごと記載済み
- **20**: お知らせは「全体向け（`class_id IS NULL`）+ そのクラス向け」を表示。掲載期間の絞り込みは RLS がやるのでアプリ側では不要
