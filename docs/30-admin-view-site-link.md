# 30. 管理画面ヘッダーに「生徒ページ」導線を追加

**依存**: 24（共通シェル）/ 29
**参照**: DESIGN.md §8（管理画面のアクセントはスカイ固定・タップ44px）

## 目的

記録カード・お知らせ・次回のじゅぎょうを登録したあと、**先生が「生徒さんの見た目」で確認する**
導線が管理画面に無かった（URL を手打ちするしかなかった）。ヘッダーに `/kiroku` へのボタンを置く。

きっかけ: 次回のじゅぎょうを月曜クラスのカードに誤入力し、金曜クラスのページを見て
「登録したのに見れない」となった件（この導線があれば先生自身がその場で気づける）。

## メモ

- 別タブで開いた `/kiroku` は**合言葉 Cookie が別途必要**。管理者もそのブラウザで一度も
  入れていなければ合言葉画面が出る（`kiroku_gate` は `path=/kiroku`・httpOnly・1年）。
  仕様どおりで、iPhone のホーム画面アプリは Safari と Cookie の保管庫が別な点も従来どおり。
