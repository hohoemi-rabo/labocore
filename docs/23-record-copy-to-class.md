# 23. 記録カードの他クラスへのコピー（下書き複製）

**依存**: 16
**参照**: REQUIREMENTS_phase2.md §2・§8.1
**マイルストーン**: M2

## 目的

同じテーマを複数クラスで行う週の入力負荷を下げる。既存カードから「別のクラスに複製」→ クラスと日付を選ぶと**下書き**が作られ、手直しして公開する。

## Todo

- [ ] 一覧または編集画面に「別のクラスに複製」アクションを追加: コピー先クラス（active・元と同じクラスは除外）+ 日付を選ぶ UI
- [ ] Server Action: テーマ・ひとことメモ・プロンプトを複製し、**`status='draft'`** で新規作成する（公開状態はコピーしない）
- [ ] 画像は **R2 オブジェクトもコピーして独立させる**（`r2.ts` の `copyImage`）。URL 共有にすると元カード削除時に複製側の画像も消えるため
- [ ] `UNIQUE(class_id, lesson_date)` 違反（23505）は「コピー先のその日付には既に記録があります」と表示する
- [ ] 複製成功後はコピー先の編集画面へ遷移する（手直し → 公開の流れに乗せる）

## 完了条件

- 例: 木曜の記録を金曜クラスへ複製 → 手直し → 公開、が一連で行える
- 複製後に元カードを削除しても、複製側の写真が表示され続ける
