# 23. 記録カードの他クラスへのコピー（下書き複製）

**依存**: 16
**参照**: REQUIREMENTS_phase2.md §2・§8.1
**マイルストーン**: M2

## 目的

同じテーマを複数クラスで行う週の入力負荷を下げる。既存カードから「別のクラスに複製」→ クラスと日付を選ぶと**下書き**が作られ、手直しして公開する。
